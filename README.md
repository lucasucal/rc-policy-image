# rc-policy-image

Generated mirror of the Docker build context of the Reality Check policy image. **Do not edit
here.** The source of truth is the private monorepo; this repo is regenerated by
`runtime/tools/sync_build_repo.sh` there, and exists only so the image can be built on free
GitHub-hosted runners (native amd64 and arm64, no QEMU).

Contents: `runtime/` (Dockerfile, hashed dependency locks, `rc_runtime`, build tools) and
`starter/rc_sdk/`. Build context is the repo root:

    docker buildx build -f runtime/Dockerfile --build-arg BASE_IMAGE=... .

Release: push a tag `vN` (or run the `build-image` workflow). It builds each architecture natively,
pushes by digest to `ghcr.io/lucasucal/rc-policy*`, creates the multi-arch manifest plus
`:<tag>-amd64` / `:<tag>-arm64` tags, and uploads each arch's package inventory as artifacts.

No license file is included: the monorepo has none for these files, so no license is granted.
